# Demo video and accessible walkthrough

[Play or download the 85-second video](demo.mp4).

This is a silent portfolio demonstration using a fictional agency and fictional listings.
The four application examples preserve footage supplied with the original project. They are
not a newly recorded evaluation of version 1.1.0. Their relative playback timing is unchanged;
the opening and closing cards were replaced, and the old tax-answer scene was removed.

| Time | Content |
|---|---|
| 0:00–0:05 | Project title, fictional-data label and explanation of the recording |
| 0:05–about 0:19 | A selling-commission question, answer and company-document source |
| About 0:19–0:33 | Utrecht properties filtered by sale price below EUR 500,000 |
| About 0:33–0:50 | Rental income calculation combining the NL-2002 listing with policy sources |
| About 0:50–1:09 | A managing-director question that the dataset cannot answer |
| 1:09–1:17 | Clearly labelled explanation of the optional, domain-restricted web-search feature |
| 1:17–1:25 | Historical 28/30 rule-based evaluation result, with date/model/web-disabled scope |

The web overview is an explanation, not a simulated model result. The removed original scene
showed an inaccurate tax threshold in a secondary-source excerpt. It has not been replaced
with a fabricated live response. To demonstrate current web-answer quality, record a fresh
run using authoritative sources and inspect the generated answer before sharing it.

The closing score is from 14 November 2026, before the release fixes. The small rule-based
question set cannot establish general accuracy, and web search was disabled in that run.
See [the recorded baseline](../evals/RESULTS.md) and [current validation](VALIDATION.md).

The screenshot in the README is also an original recorded response. It illustrates the
multi-source calculation, not a guarantee that every answer will have the same quality.
