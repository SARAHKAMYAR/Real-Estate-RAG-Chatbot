# Sharing this demo on GitHub

1. Extract the supplied release ZIP and use the contents of its `real-estate-rag/` directory
   as the repository root. Do not upload the local `.venv`, model caches, databases or `.env`.
2. Create the repository under your own account. The README, MIT license, sample data,
   screenshot, revised video, dependency lock, CI and maintainer guidance are included.
3. Enable private vulnerability reporting and dependency alerts where available. Require
   the CI check before merging changes. Review the first remote Actions run before claiming
   that Docker/Linux CI is verified.
4. Link the README's demo video or upload it as a GitHub attachment if inline playback is
   preferred. The README already includes a relative video link and textual walkthrough.
5. Describe it as a **local portfolio demo using fictional data**. Refer to the 28/30 answer
   score as a historical rule-based baseline. The current retrieval check is 17/17.

No repository has been published by preparing these files. If you add them to an existing
repository, inspect its entire history for credentials before making it public. The clean
release archive does not establish that an older Git history is clean.

For a public hosted application, complete the deployment requirements in [SECURITY.md](../SECURITY.md)
before changing the local-only network bindings.
